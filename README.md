# FlowMail: AI-Powered Outlook Add-in

## Overview
FlowMail is an AI-powered Outlook add-in designed to assist students in drafting emails in a professional and academic manner. The add-in leverages **GPT-3.5** to provide context-aware email suggestions, helping students communicate effectively.

## Features
- **AI-Assisted Email Drafting**: Generates professional and academically appropriate email content.
- **Context-Aware Suggestions**: Understands the user's intent and provides relevant recommendations.
- **Seamless Integration**: Works directly within Microsoft Outlook.
- **User-Friendly Interface**: Simple and intuitive UI for quick email composition.

## Technology Stack
- **Frontend**: JavaScript, Office.js
- **Backend**: Python, Flask (for handling API requests)
- **AI Model**: GPT-3.5 (for natural language processing)

## Implementation Highlights
- Developed the add-in as part of my **master’s project**, integrating AI to enhance productivity.
- Initially experimented with the **RoBERTa model** for emotion recognition before pivoting to **GPT-3.5** for improved results.
- Built a **Flask API** to process user inputs and fetch AI-generated responses.
- Optimized the user experience with **Javascript, jQuery**, ensuring seamless interaction within Outlook.

## Impact
- Enables students to **write professional emails with confidence**.
- Reduces time spent on drafting emails while maintaining clarity and politeness.
- Helps non-native English speakers communicate effectively in academic settings.

## Future Enhancements
- **Personalized Suggestions**: Train the model based on user preferences.
- **Multilingual Support**: Expand to different languages.
